How it would run

Guardrails and delivery

Built into every template

  • Claims are per-client switches, set from OpenBrain: LHR shows no star ratings, no BBB badge and no geo call-out, and says "labor" warranty. GC never names the slab supplier.
  • No fake reviews or invented app screens. Real Google ratings only when the client has them.
  • Financing stays off for LHR, Midwest, Vistaguard and GC. Anywhere else, a monthly payment appears only with the full disclosure line (TILA/Reg Z). "$0 down options available" is the safe default.
  • Roofing: no "free roof", "we pay your deductible" or "we handle your claim". Illinois ads carry the license line.
  • "10 homes", "7 days" and "this month" are variables the client confirms before launch.
  • One price per ad, except a deliberate ladder ad.

What editors receive

  • 1080×1920, 30 fps. Overlays as ProRes 4444 with alpha (.mov) and WebM alpha for CapCut. Inserts as MP4.
  • One Drive folder per client with every variant pre-rendered in their colors, named by offer: GC_price-shock_$1995.mov.
  • Beat times are listed for each file so it lines up with the voiceover.
  • A new offer means a new row in a sheet. I re-render the set in minutes, not hours of After Effects.
  • A short editor guide: which template fits which script beat (hook, offer, inclusions, process, proof, CTA).
